# taste-gate

AI 影像/内容生产的审美闸门技能：当内容可无限量产时，唯一稀缺且不过期的是人的审美与叙事判断力——人从"制作者"变成"裁判"。让 AI 负责"多"，让人负责"好"；流程管住数量下限，标准管住品质上限，其余的交给比较。

一句话：**技术护城河两个月一更新，审美不会。**

## 方法论底座

- 奥卡姆剃刀主题：技术难题被模型迭代自动解决后，唯一稀缺不过期的是审美与叙事判断力
- 技术保质期：换脸-调色工作流两月作废；角色一致性"让模型去解决"——工具层死磕磕赢也是暂时的
- 1000 选 1：AI 量产的是废片/备选/淘汰片段，精品化的才叫作品；比较是质量的前提
- 内容分层：快餐式交 AI 效率，精品与否由人定义——"人决定内容的上限，而不是 AI 本身"
- AI 味剧本：ChatGPT/Claude 写的本子共情弱；"还不错"人人可得就一文不值
- 别跟模型硬刚：200 场戏服装按五景别×三视图资产化；模型短板用导演思维绕
- 审美占 70%–90%：AI 导演审美权重；成熟 AI 剧组约七岗位，含"生成师/抽卡师"新工种
- 瓶颈在人：能参与生产的人/便宜的 Token/更优秀的创作者；最隐蔽的是"品控对不齐"
- 模因：基因先天，模因后天阅历攒出；工具平权抹平"会不会做"，放大"见过世面"的差距

## 解决什么

| 痛点 | 本技能的做法 |
|---|---|
| 品控对不齐，做完才发现是废活 | 立项三件套：风格参考板（3–5 张）+负面清单+已通过的验收样例 |
| 跨场一致性翻车 | 一致性前移：角色卡四要素+服装/场景按景别×三视图资产化 |
| 跑一两次就收工 | 候选下限写成硬工序（关键≥100/普通≥20，没跑够不进下一环） |
| 死磕镜头成本失控 | 抽卡时间盒（分钟+次数双限），到点换方案不硬刚 |
| 算力成本高 | 降本三件套：提示词瘦身（500→200 字）+批次复用+资产复用，季度项目 |
| 工作流押注两月保质期 | 轻流程重资产：模型更新后还成立的经验才当护城河 |
| 时间追工具教程 | 投资攒模因：阅片/拉片/素材库半衰期一辈子，工具时间≤20% |
| 招人/自评没标准 | 审美权重显性化：决策位≥70%、执行位镜头语言必懂；先问卖判断力还是产能 |

## 安装

复制本目录到 `~/.agents/skills/`（或你的 Skill 加载路径）即可。

## 自检

```bash
python scripts/validate.py tests/sample_good.json   # 必须 exit 0
python scripts/validate.py tests/sample_bad.json    # 必须 exit 1
```
