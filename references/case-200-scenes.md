# 案例：200 场中剧的资产化拆解 + 1000选1 的经济学

> 来源：孙汀颜 200 场中剧实践（原文案例）+ 南墙 1000 选 1 分镜实践。
> 本文件回答两个问题：资产化到底做到什么粒度？1000 选 1 的钱花在哪？

## 一、200 场中剧：服装资产库的实际粒度

原文事实：**前期把每场戏每套服装的远/全/中/近/特五景别加三视图建成资产。**

### 为什么是"每场戏×每套服装"这个粒度

- **角色一致性**（同一角色跨场不换脸）只是下限——AI 模型更新后这层"让模型去解决"了
- 真正废卡的是**跨场一致性**：同一套衣服第 3 场和第 17 场看起来是两套衣服 → 观众出戏 → 整场废
- 解法：服装作为**独立资产**管理（不属于某场），每场戏引用资产而不是现场生成

### 资产库实际结构（200 场量级）

```
角色A/
  设定卡.md            # 性格/习惯动作/口头禅/转变弧光
  服装-常服/
    远.jpg 全.jpg 中.jpg 近.jpg 特.jpg
    三视图-正.jpg 侧.jpg 背.jpg
  服装-战损装/
    （同上，转变弧光第 8 幕启用）
场景-主屋/
  远.jpg 全.jpg 中.jpg
  三视图（俯视/正视/剖面）
```

### 前期成本 vs 后期节省

| 项 | 不资产化 | 资产化 |
|---|---|---|
| 前期 | 0 天 | +1~2 天（200 场量级） |
| 单场生成一致率 | ~60%（现场赌） | ~90%（引用资产） |
| 跨场穿帮返工 | 高频 | 低 |
| 200 场总废卡 | 高（原文："后期少废一千张卡"） | 低 |

**账**：前期多花一天，后期少废一千张卡——一千张卡的生成成本+人工挑选时间 ≫ 一天整理时间。这是"轻流程重资产"的实证：资产库在模型更新后依然成立（模型越更新，一致性越依赖外部资产）。

## 二、1000 选 1 的经济学

原文事实：南墙做一个分镜，先跑几百上千张图，只留一张进入正式制作。

### 为什么"量产的是废片"不算浪费

```
1000 张候选 = 一个分布采样
  ├─ 99% 废片：不是"失败"，是"分布的边缘"——它告诉你模型在这个提示词下的方差
  ├─ 1% 备选：进入候选池，供二次比较
  └─ 1 张 作品：通过审美闸门（风格板+负面清单+验收样例）进入正式制作
```

**比较是质量的前提，没有候选就没有选择权**——只跑 3 张，你选的是"3 张里最好的"，不是"好的"。

### 成本账（示意，按实际单价代入）

| 策略 | 单分镜生成量 | 单分镜成本 | 通过率 | 期望成本/个可用分镜 |
|---|---|---|---|---|
| 跑 3 张收工 | 3 | 3×单价 | ~5%（3 张里出精品的概率极低） | 60×单价（还要人工返工） |
| 1000 选 1 | 1000 | 1000×单价 | ~95%（分布足够大必有一个过闸门） | ~1050×单价，但零返工 |
| 100 张+提示词迭代 3 轮 | ~300 | 300×单价 | ~80% | ~375×单价+提示词迭代时间 |

**结论**：1000 选 1 是"用算力换审美确定性"，适合**关键定调镜头**（错了全片定调废）；普通镜头用"100 张+提示词迭代"性价比更高。这就是第 3 步候选下限表分级（关键 ≥100、普通 ≥20）的来源。

### 时间盒的配套逻辑

1000 选 1 不加时间盒 = 抽卡师可以无限抽（成本失控）。所以：
- 关键镜头：30 分钟/20 次上限内**先迭代提示词方向**（每 5 张评估一次分布），方向对再放量
- 方向错（连续 5 张同类废法）→ 立即换方向，已抽的 1000 张配额重新分配

## 三、可迁移：非影视场景的同构

"200 场×五景别×三视图"的资产化结构和"1000 选 1"的工序，同构迁移到其他 AI 内容生产：

| 影视 | 同构迁移（如 AI 内容/图像生产线） |
|---|---|
| 服装资产库（五景别×三视图） | 品牌视觉资产库（每 SKU 的多规格/多平台尺寸/多背景变体） |
| 角色设定卡 | 品牌人设卡（语气/口头禅/禁区/转变节点=品牌调性迁移） |
| 1000 选 1 分镜 | 1000 选 1 素材（关键广告位候选下限 100，普通位 20） |
| 抽卡时间盒 | 单 SKU 单变体时间盒，到点换创意方向不换模型参数 |
| 风格参考板+负面清单 | 品牌风格板+禁用元素清单（立项对齐书） |

**判定**：任何"AI 量产+人筛"的生产线，都能套这个结构；套不上（没有"量产"环节）的场景不适用本技能，走单次调用即可（见 ai-task-economy 的任务量公式）。
