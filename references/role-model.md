# 岗位模型：AI 剧组七岗位与审美权重两把尺子

> 原文事实：成熟 AI 剧组约七个岗位，含新工种"生成师/抽卡师"；朱雷蒙招 AI 导演审美权重 70%+，孙汀颜给到 90%+。

## 一、AI 剧组七岗位（参照结构）

| # | 岗位 | 卖判断力还是产能 | 审美权重 | 核心职责 | 淘汰信号 |
|---|---|---|---|---|---|
| 1 | AI 导演 | 判断力 | 70–90% | 定调、分镜决策、"什么算好"的最终裁判 | 审美判断与参考板漂移 |
| 2 | 编剧/叙事 | 判断力 | 50–70% | 叙事结构、人物弧光；**几乎不用 AI 写剧本**（AI 味共情弱），最多策划阶段当创意助手 | 剧本共情测试不过 |
| 3 | 生成师/抽卡师（新工种） | 产能+镜头语言 | 20–40% | 提示词工程、候选量产、时间盒内抽卡 | 废卡率高/成本控不住 |
| 4 | 资产管理员 | 产能 | 10–30% | 角色卡/服装库/场景库/风格库维护，资产命中率 | 跨场穿帮频发 |
| 5 | 品控/验收 | 判断力 | 40–60% | 按验收样例过闸，"不做什么"清单执行 | 放行废片/标准漂移 |
| 6 | 后期/合成 | 产能 | 20–40% | 镜头组接、节奏控制、一致性修补 | 节奏与参考板不符 |
| 7 | 制片/成本 | 判断力+数据 | 20–40% | 时间盒监控、降本三件套、算力预算 | 成本失控无预警 |

**七岗最小配置**：小团队可合并（导演兼品控、生成师兼资产），但**"卖判断力"与"卖产能"的分工不能省**——让产能位做判断（抽卡师定调）或判断位做产能（导演自己抽卡）都是结构错误。

## 二、审美权重两把尺子

### 尺子 1：决策位（导演/品控/编剧）

```
审美权重 ≥70% 的判定：
  这个岗位的核心产出是"判断"（选哪张/过不过/怎么改），不是"产出量"
  → 审美训练时间 > 工具学习时间
  → 招人第一问："你见过什么好东西？给我看 3 个。"
  → 第二问："这个为什么好？好在哪一环（镜头/光影/节奏/叙事）？"
  → 答不出"哪一环"的=感觉派，判断力不可迁移，不招
```

### 尺子 2：执行位（生成师/后期/资产）

```
审美权重可退居其次，但镜头语言和逻辑必须懂：
  不懂镜头语言的生成师：
    - 提示词只能抄，不能按叙事意图改 → 废卡率高
    - 抽卡时认不出"差一点"的候选 → 成本控不住
    - 时间盒到点不会换方案 → 死磕
  判定问题："这个镜头为什么这么拍？如果换景别叙事损失什么？"
  答得出=镜头语言内化，可培养审美；答不出=先补镜头语言再谈其他
```

## 三、定位自问（"我这个位置到底卖什么"）

```
问 1：我的产出是被"数"的（条数/张数）还是被"评"的（过闸率/定调质量）？
  被数 → 产能位，优化单位成本+速度
  被评 → 判断位，优化判断准确率（建立自己的参考板+负面清单）

问 2：模型大版本更新后，我的岗位是"重学工具"还是"重新校准判断"？
  重学工具 → 半衰期 2 个月的岗位，必须同步攒模因（每周输入）
  重新校准判断 → 判断位，更新的是"好"的定义（重校验收样例）

问 3：我升下一级的台阶是"产得更多"还是"判得更准"？
  判得更准 → 当前是执行位，判断力占比要从 20% 提到 40%+ 才能升
  产得更多 → 当前是产能位，天花板是"生成器"，要主动转判断位
```

## 四、招人问题清单（AI 导演位，原文"晚上刷抖音看到美学好的片子会去后台挖人"的可复制流程）

1. 给我看你最近 3 个最满意的作品，说每个为什么好（哪一环）
2. 给你一个废片，30 秒内说出它坏在哪（负面清单能力）
3. 这个镜头我打算换景别，你的反对意见是什么（判断力 vs 执行力）
4. 你最近 2 个月看了什么片/作品？拆了哪个（模因投入证据）
5. 工具大版本更新时你的第一反应是学什么（追新=追工具；不变=追资产，后者更好）

**红旗**：只会说"感觉"、参考系是 AI 生成内容（AI 味审美闭环）、把"跑得多"当能力证明。
**绿旗**：参考系是人创作的经典作品、能说出"哪一环好"、有自建风格素材库。
